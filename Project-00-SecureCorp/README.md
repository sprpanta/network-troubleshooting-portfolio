# SecureCorp — Enterprise Network & Cybersecurity Lab

An enterprise networking and cybersecurity simulation
built using Cisco Packet Tracer.

## Technologies
- VLANs and inter-VLAN routing
- DHCP and DHCP relay
- OSPF dynamic routing
- ACLs and SSH security
- Switch port security
- NAT/PAT and static port forwarding
- Branch office connectivity
- DMZ web server

## Testing
Connectivity, routing, access controls, and NAT
were tested using Cisco IOS commands.

## Known Limitation
DMZ isolation was not consistently enforced during
testing and requires further investigation.
