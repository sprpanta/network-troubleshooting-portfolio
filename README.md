# LAN & DHCP Troubleshooting

Cisco Packet Tracer troubleshooting lab featuring
two LANs, DHCP, routing, and five resolved incidents.

## Troubleshooting Tickets

- INC-001: Router Interface Administratively Down
- INC-002: Incorrect Default Gateway
- INC-003: Incorrect Subnet Mask and Proxy ARP
- INC-004: Incorrect DHCP Default Gateway
- INC-005: Missing DHCP Network Statement

## Tools
- Cisco Packet Tracer
- Cisco IOS CLI
- Ping, ARP, and DHCP diagnostics
